# 📖 About This Repository

Welcome to the **60 Days of PySpark & Spark SQL Challenge**!

This repository is a structured learning journey designed to help beginners and aspiring Data Engineers master **PySpark**, **Spark SQL**, and real-world data processing concepts through daily practice.

Unlike traditional tutorials, this challenge focuses on **learning by solving problems**.

Each day contains carefully designed questions that gradually increase in difficulty, helping you build both conceptual understanding and practical coding skills.

By the end of this challenge, you'll be confident in writing PySpark code, solving Spark SQL problems, and handling common Data Engineering interview questions.
